# React Practice
## Overview
- This document provides information about React practice. 
- In this practice, I will create a simple Note-keeping website. 
- This website will apply React to manage and organize notes efficiently.
## TECHNICAL
- HTML5 defines the website's structure.
- CSS3 is used to style the HTML elements.
- React adds interactivity and dynamic behavior to websites.
## TIMELINE
- 22 days (Feb 6, 2025 to Feb 28, 2025)
## TEAM SIZE
- 1 dev
## EDITOR
- Visual Studio Code
## TARGET
- Understand and apply knowledge of HTML5, CSS3, and JavaScript (with ES6 syntax).
- Be able to apply advanced React concepts: Context and Custom Hooks.
- Set up and implement unit tests for components.
- Improve the ability to handle state, and props and to optimize re-render.

## HOW TO RUN
- Clone the json-server repository
```bash
git clone https://github.com/Vietprole/json-server.git
```

- Move to the cloned json-server repository folder
```bash
cd json-server
```

- Install packages
```bash
npm install
```

- Run json-server
```bash
npm start
```

- Clone the main repository in another terminal

```bash
git clone https://github.com/Vietprole/react-training-internship.git
```

- Move to the cloned main repository folder
```bash
cd react-training-internship
```

- Checkout to branch `feat/practice`
```bash
git checkout feat/practice
```

- Install packages
```bash
npm install
```

- Run the app
```bash
npm run dev
```

- View app on browser: http://localhost:5173/
### Additional commands
- Run storybook
```bash
npm run storybook
```
- View storybook on browser: http://localhost:6006/

- Run test

npm run test

- Run test coverage
